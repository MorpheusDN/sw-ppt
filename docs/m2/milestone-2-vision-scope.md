## 1. Vision

长程多轮对话系统在处理跨会话用户状态时面临根本性困难。现有检索增强方法依赖静态语义匹配，无法建模记忆单元之间的时序依赖与状态演化，导致过期信息在生成过程中产生干扰。

本项目提出一种**动态记忆管理框架**，通过结构化表示对话中的实体、事件与时间属性，构建带版本控制的记忆库。框架引入**状态关系判定机制**，自动识别记忆间的保留、更新、替代与冲突关系，并依据查询上下文筛选有效记忆子集。

**研究目标：**
- 建立可扩展的记忆结构化标准；
- 实现基于时间推理与语义一致性的状态更新算法；
- 开发可视化分析界面；
- 设计多维度评测体系，与基线方法对比。

最终成果将为长对话场景下的记忆增强型系统提供可复现的参考实现与评测基准。

## 2. Scope

### 2.1 In-Scope

| 模块 | 内容 |
|------|------|
| 数据预处理 | 基于 LoCoMo 数据集，对话分段、清洗、实体与事件抽取，输出结构化记忆单元（JSON） |
| 动态记忆模型 | 定义记忆单元结构（ID、摘要、时间戳、来源、置信度、状态标签），支持插入/查询/更新/废弃 |
| 状态关系判定 | 定义 RETAIN / UPDATE / SUPERSEDE / CONFLICT 四类关系及判定规则，处理部分更新与隐含冲突 |
| 记忆检索 | 关键词 + 向量相似度混合检索，依据状态关系过滤过期记忆，生成精简上下文 |
| 可视化界面 | React + ECharts，支持记忆树浏览、原始对话回溯、关系图谱渲染、检索结果对照 |
| 评测体系 | 回答准确率（F1）、证据召回率（Recall@K）、状态判断准确率；与 TF-IDF、Sentence-BERT 基线对比 |

### 2.2 Out-of-Scope

- **多语言支持**：仅处理英文对话；
- **语音与多模态**：仅处理文本转录；
- **实时对话集成**：仅离线批处理与静态分析；
- **复杂图神经网络**：状态判定基于规则与时间推理，不用 GNN；
- **跨数据集迁移**：评测仅在 LoCoMo 上进行；
- **分布式部署**：单机原型，不做容器化与高并发优化。

## 4. Evaluation Plan

| 指标 | 说明 |
|------|------|
| 回答准确率 | LoCoMo 问答对，精确匹配 + 语义相似度，计算 F1 |
| 证据记忆召回率 | 标注相关记忆片段，计算 Recall@K |
| 状态更新判断准确率 | 构造状态演化用例，计算关系分类的 P / R / F1 |

**实验设置：** 开发集 4 段对话用于调参，测试集 2 段对话用于最终评测，重复三次取平均。

**基线方法：** 全文检索（TF-IDF）、向量检索（Sentence-BERT）。对比实验在相同检索接口下进行，仅替换记忆筛选模块。
