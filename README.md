# RISC-V / LoCoMo Dynamic Memory Management

Team 2 / RISC-V，2026 秋季软件需求工程课程项目。仓库已接入 Python + React/ECharts 系统、公开 LoCoMo、MiniLM 和 DistilBERT；包含 M4/M5 文档、展示和真实实验结果，54 项测试通过。现有 M1/M2、正式 M3、会议纪要、看板和计划保留。

正式 M3 需求基线仍为 PR #14 合并的 [SRS v1.0](docs/m3/milestone-3-srs.md)，构建和提交文件见 [M3 说明](docs/m3/README.md)。新增 `M3-SRS.*` 及详细附录属于实现补充快照，不替换该正式基线；其中需求编号不能直接代替正式 SRS 的需求编号。

## 先运行

安装 Python 3.12，双击根目录 run.bat。它在 src/.venv 创建环境并安装锁定依赖，Git 不包含 ONNX 权重；首次启动按固定版本下载并校验，之后推理离线。启动后打开 http://127.0.0.1:8765 。若只要规则演示，可用 run-basic.bat。

页面可演示 Caroline 当前与历史收养状态、来源关系图。一般英文问题勾选“通用问答”，选择 Vector RAG。Full Text 遍历完整历史窗口，CPU 查询较慢。模型回答为原文单跨度，不能保证多跳与完整列表质量。
